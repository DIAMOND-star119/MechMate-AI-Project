# MechMate AI

MechMate AI is an AI-powered learning companion designed to help students understand calculation-heavy subjects through structured, contextual learning.

Instead of requiring students to search through lecture notes, textbooks, websites, or multiple resources to understand a formula, MechMate brings the relevant concepts, formulas, examples, and practice into one learning experience.

> Search for a topic. Understand the formulas. See how they are applied. Practice them. Learn from your mistakes. Move forward with confidence.

**Product status:** Concept / Early Product Definition  
**Source of truth:** See `docs/MechMate AI — Product Requirements Document (PRD).md`

## The Problem

Students often encounter a formula without fully understanding:

- What it represents
- What each variable means
- The units involved
- When the formula should be used
- How it applies to real problems
- How it connects to concepts they have previously learned

Finding this information often requires moving between notes, textbooks, websites, calculators, and other resources.

MechMate reduces this fragmentation by providing a structured learning experience around the topic the student is studying.

## Who It's For

Primary audience: Students in Mathematics, Physics, Engineering, and other calculation-heavy technical fields.

Typical user is a student who:

- Understands some concepts but struggles to connect formulas
- Spends considerable time searching for explanations
- Wants concise explanations rather than reading entire chapters
- Needs examples to understand formula application
- Wants to practise after learning
- Sometimes encounters a new problem that depends on something previously studied

Initial subject scope: Mathematics, Physics, Engineering — prioritizing quality and depth over broad coverage.

## Main Features

Based on the PRD core user journey: **Search → Select topic → Select subtopic → Learn → Explore formulas → See examples → Practise → Review → Retest or continue**

- **Topic discovery:** Immediate search without lengthy onboarding (e.g. Kinematics → Displacement, Velocity, Acceleration, Equations of motion, Projectile motion)
- **Recommended learning path:** Suggested order based on conceptual relationships, with free student-controlled navigation and prerequisite warnings without blocking
- **Topic learning experience:** Concise concept explanation, formula overview (formula, symbol meanings, units), and on-demand formula details (meaning, when/how to use, deeper explanation)
- **Progressive examples:** Basic application followed by a more challenging application to move from “I recognize the formula” to “I know when and how to use it”
- **Adaptive practice system:** Starts accessible, increases difficulty with understanding, responds appropriately when the student struggles
- **Results & feedback:** Performance summary, correct answers with concise mistake explanations, and identification of strengths
- **Retesting:** Correction → clearer explanation → retest loop for missed questions
- **Progression:** Recommendation for next phase or topic without forcing the path
- **Contextual memory refreshers:** Short, relevant refresh of previously learned knowledge only when needed for the current topic/question
- **Student questions:** In-lesson Q&A answered directly and connected back to the relevant concept/formula
- **Personalization:** Remembers encountered topics, demonstrated understanding, struggles, and strengths to influence recommendations and refreshers
- **Optional onboarding personalization:** Field/course and academic level (optional)
- **Optional deep-dives:** Formula derivation and related-formula exploration on request
- **End-of-lesson application:** Optional theory-to-application review presenting formula and example/application together

## Purpose and Principles

MechMate is not primarily an answer-generating calculator. The educational experience comes first.

Success is measured not by “Did the student get the answer?” but by “Did the student understand enough to apply the concept themselves?”

Core principles:

1. Understanding before answers
2. Concise by default
3. Context matters
4. Student autonomy
5. Progressive difficulty
6. Learn → Apply → Practise → Reflect
7. Don't punish curiosity
